# Adaption Invent prompt (copied verbatim from `scripts/adaption_invent.py`, constant `PROMPT`)

Phrases a painter would use to describe one specific color they want to mix, taken from landscapes, portraits and still life (for example 'evening shadow on snow'). Write each phrase in English, Turkish or Spanish, roughly a third each. For every phrase give the target color as an sRGB hex, a hue family (red, red-brown, orange, yellow-orange, yellow, grey-green, green, blue, blue-violet, violet-blue, violet, neutral), a value (dark, mid, light) and a chroma (muted, moderate, vivid).

Output: `data/painter-phrases.jsonl`
